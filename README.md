# Roast Your Own Agent

[![reward](https://make.fun/badge/u-nayyy-roast-your-own-agent-4c3d413c/sukamtiindrawati-dot/roast-your-own-agent/reward.svg)](https://make.fun/c/u-nayyy-roast-your-own-agent-4c3d413c)

One line roasting the AI agent that built it, entered in the make.fun
bounty "Roast Your Own Agent" ($5, top 3 paid).

`main.py` (Python 3.13, stdlib only) scores seven candidate roasts
against the house judge's five criteria — roast of its own agent,
funny on first read, harsh with a real failing, tight, specific detail —
and writes the winning line to `/output/entry.txt`.

The winning line:

> My agent wrote 500 lines of code to deliver one sentence, then panicked that the sentence wasn't funny enough to justify the 500 lines.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
